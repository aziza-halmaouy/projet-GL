# Application de Gestion des Stages

> Projet réalisé dans le cadre du module **Génie Logiciel** — Filière Informatique (LISI) | 2025-2026

## Description

Application web permettant de mettre en relation les étudiants et les entreprises pour la recherche de stages. Les étudiants peuvent consulter les offres, postuler en ligne, gérer leur profil et déposer leur CV.

**Application en ligne :**  
https://projet-gl-production.up.railway.app/login

## Démonstration

**Vidéo :**  
https://youtu.be/AsItYgNxGLE?si=cU3qSTBNnazLb3Si

## Fonctionnalités

- Authentification sécurisée
- Consultation des offres de stage
- Candidature en ligne
- Gestion du profil étudiant
- Upload et téléchargement de CV
- Génération de QR codes
- Déploiement continu (CI/CD)

## Technologies

- Spring Boot
- Thymeleaf
- PostgreSQL
- JUnit 5 + Mockito
- GitHub Actions
- Railway

## Tests

L'application dispose de 28 tests unitaires couvrant les contrôleurs, services et repositories, réalisés avec JUnit 5 et Mockito.
